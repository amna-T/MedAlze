# Deployment Fix - Worker Timeout Issue

## Current Problem

Your backend is experiencing **WORKER TIMEOUT** errors:
```
[CRITICAL] WORKER TIMEOUT (pid:84)
[ERROR] Worker (pid:84) was sent SIGKILL! Perhaps out of memory?
```

This happens because:
1. The DenseNet-121 model takes **>30 seconds** to load
2. Gunicorn's default timeout is **30 seconds**
3. Worker gets killed before model finishes loading

## What I Did

### ✅ Commit 1: Increased Timeout to 300 seconds
**File:** `render.yaml`
```yaml
startCommand: cd backend && gunicorn -w 1 --timeout 300 app:app
```

### Why 300 seconds?
- DenseNet-121 model load: ~40-60 seconds on free tier
- Safe margin: 300 seconds (5 minutes)
- This prevents worker timeout on first prediction request
